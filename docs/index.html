Here's a script that archives everything in the current directory and excludes its own output:

bashCopy
#!/usr/bin/env bash
set -euo pipefail

# timestamped archive of the current folder
stamp=$(date +"%Y-%m-%d_%H-%M-%S")
zip -r "backup_${stamp}.zip" . -x "backup_*.zip"

Run it inside the folder you want to archive; the new .zip lands right there.

Transparency

Tools don't make a model honest.
They make it checkable.

A search or documentation tool returns what matched one query, never the whole reference — and a model can confidently call what it did not receive nonexistent. A prompt could not fix that; we measured it making things worse. So every tool call opens the raw output the model actually got, stored with the message.

What you get

Control first, everything else built in.

Routing

Manual, always

Pick the server and model for every message. Servers that are asleep or unreachable are hidden, so they cannot be picked by mistake.

Backends

One UI, any server

Native Ollama and any OpenAI-compatible API — OpenRouter, LM Studio, vLLM, llama.cpp — side by side.

Streaming

With reasoning

Answers stream as they generate; reasoning shows in its own pane. Esc stops any response.

Context

Vision & documents

Paste images to vision models; attach PDFs, docx or code as lossless text on any model.

Tools

Web search and MCP

Bundled web search plus any MCP server. Read-only tools run freely; anything that changes state asks you first.

Access & secrets

Multi-user

Roles, private chats, registration you can close. API keys and MCP tokens are encrypted in the database.

Get started

Two ways in. Both take a few minutes.

Easiest

Let your coding agent do it

Paste one prompt into Claude Code, Codex or any coding agent on the machine that should host Calivi. It checks the machine, installs what is missing, starts Calivi, verifies it and hands you the URL.

Read it first
By hand

Three commands

Needs only Docker with Compose.

$ git clone https://github.com/orkun-soylu/calivi.git
$ cd calivi
$ docker compose up -d --build

Then open http://localhost:8090 and sign up right away — the first account becomes the admin. Add a model server under Settings → Servers, pick it from the top bar, and chat. Settings, backups and HTTPS are in the README.
